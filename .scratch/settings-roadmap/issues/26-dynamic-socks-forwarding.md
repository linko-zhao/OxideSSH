# 26: Dynamic SOCKS 转发

**What to build:** 用户可建立动态转发规则，使本地 SOCKS 客户端通过 SSH 会话访问客户端请求的目标地址。

**Blocked by:** 24: 本地端口转发

**Status:** blocked

- [ ] 动态转发规则可在现有规则管理界面配置、启动、停止和删除。
- [ ] 本地 SOCKS 客户端能通过该规则访问不同目标地址和端口。
- [ ] 停止规则会关闭 SOCKS 监听器并终止对应转发。
- [ ] 非法 SOCKS 请求、连接失败和 SSH 断连会产生真实状态，不影响其他规则。
- [ ] 既有本地转发规则及配置兼容性不回归。
