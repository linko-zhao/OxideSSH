# OxideSSH项目
## 项目概述

这是一个ssh客户端，可以用于管理ssh连接

## 技术栈

- Rust
- GPUI

## 常用命令
- **Build**: `cargo build`
- **Test**: `cargo test`
- **Lint**: `cargo clippy --all-targets`
